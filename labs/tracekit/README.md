# Tracekit

A zero-backend browser environment inspector. Tracekit shows a visitor what their browser exposes through ordinary web APIs, including display information, locale/timezone, storage availability, hardware hints, WebGL renderer information and a deterministic canvas sample.

## Run
Open `index.html` in a modern browser. No build step, account, server or API key is required.

## Privacy
The current implementation runs entirely client-side and does not transmit collected values. It is designed for visibility and education, not fingerprint spoofing or detection bypass.
